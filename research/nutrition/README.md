# Singapore nutrition and grocery research (public, sanitized)

**Status:** research archive / NOT a clinically validated nutrition plan. Last indexed: 2026-11-13 (SGT).

## Purpose
Preserve reproducible, non-personal findings for low-cost, high-protein, calorie-controlled Singapore meals. This folder is independent of FitnessPilot's application code and does **not** deploy or modify the app.

## Trust boundary
- **Public:** generalized nutrition research, source links, historical retailer price observations, methods, risks and unresolved questions.
- **Private:** editable XLSX workbooks, individual dietary targets, weight logs, actual food diary, source uploads and personal health context. These are NOT committed to this public repo.
- The exact workbook snapshots are preserved separately in the owner's private ChatGPT Library. The GitHub record preserves index, history and checksums, **not the original XLSX bytes**.
- Reusing a product listing is not confirmation of current price, composition or availability.
- A recognized source ID is not verification of an individual nutrient amount.
- Published weekly meal calculations are estimates and do not certify all vitamins/minerals.

No changes made to production, preview UI, workouts or personal logs as part of this archive.
