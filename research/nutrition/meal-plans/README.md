# Meal-planning principles (research artifact; not a prescribed diet)
An illustrative seven-day rotation used combinations of chicken, fish/sardines, tau kwa, eggs, fortified soy, Greek-style yoghurt, lentils, broccoli, spinach, carrots, oats, rice, potatoes, fruit, nuts/seeds and modest cooking oil.

## Acceptance gates for any future recipe
1. Ingredient weighed in g/ml with raw/cooked/drained status, verified match to nutrition source, edible yield when relevant.
2. Energy/protein/fiber and relevant nutrient fields have explicit data-quality states. Missing != zero.
3. Recipe and day totals fail closed if a required value is absent, invalid or unit mismatched.
4. Track planned versus actual intake separately. User completion checkbox is self-attestation, not verified full-day intake.
5. Compare vitamins and minerals only using compatible units, appropriate reference standards and complete food records; report "not audited" otherwise.
6. Do not change calorie/protein goals merely from a trend fluctuation or an unverified food video.
7. Evaluate actual 7-day weight trends, training recovery, hunger and adherence at planned review intervals.
8. Retain previous versions and research contradictions.

## Out of scope
No medical certification, no automatic food-log upload, no FitnessPilot UI/production change. Private logs reside outside public GitHub.
