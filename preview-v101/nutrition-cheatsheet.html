Recording actual progress

  1. On the Nutrition dashboard, tap Load public example or choose your own JSON to view reference targets.
  2. Loading a reference does not create a food log.
  3. Use Train → Daily check-in to record measured calories, protein and body weight.
  4. Return to Nutrition for the weekly comparison. Missing entries remain unknown; target files are not saved permanently.

R0–R6 adjustments remain manual-review reference rules. No automatic calorie changes or physique predictions.
