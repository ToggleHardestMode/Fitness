Phone ↔ PC: backup transfer

This is not automatic cloud sync. It merges distinct saved records from two FitnessPilot JSON backups without overwriting existing sets. Conflicting edits require review; no records are silently replaced or deleted.

1. Preserve both original backups

On each device: Tools → Download full backup (.json). Keep both files in a secure location. Food Diary has separate storage and is not part of this merger.

2. Inspect the other device's backup

No file selected; nothing changed.

3. Save merged file, then restore explicitly

Only after confirming zero conflicts, download the merged backup. In FitnessPilot Tools, use the existing backup restore flow and type REPLACE after separately backing up your current records. Verify counts and saved sets.

No remote upload, login or backend is involved. Restore is intentionally a separate step; this page cannot modify your saved workouts.
