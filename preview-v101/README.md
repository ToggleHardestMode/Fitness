# FitnessPilot preview

This folder contains the local-first FitnessPilot preview app, separate from the production app at the repository root. The current version is shown in the banner of [index.html](index.html), not in this document.

- [Open the preview](https://togglehardestmode.github.io/Fitness/preview-v101/)
- [Install, backup, development and safety notes](../README.md)
- [Historical release notes](../CHANGELOG.md)
- [Roadmap and verification gates](../ROADMAP.md)

Existing browser records must be backed up before any restore. Do not clear website data to refresh the preview. Workout templates and planned sets are not completed sets; `[PT Review]` flags and exercise-clearance rules remain in force.
